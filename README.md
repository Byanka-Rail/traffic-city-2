# traffic-city-2
TRAFFIC CITY 2 urban simulation

## 업데이트 올리는 법 (포병과 같은 방식)
- 새 판을 `TRAFFIC_CITY_2_v<판>.html` 이름으로 저장소 최상위에 올린다  예) TRAFFIC_CITY_2_v160.html
- 게임 안 마지막 `_BUILD_VERSION` 이 파일 이름 판과 같아야 한다 (다르면 워크플로가 멈춘다)
- 워크플로가 최신 판을 index.html 로 복사(깔린 앱은 GitHub Pages index.html 을 연다), update.json 갱신, 판 HTML 최근 10개만 유지
- index.html 은 직접 고치지 않는다
